# MyNews — 自分専用ニュース

好きなカテゴリのニュースを一画面で見るための、スマホ対応の静的Webサイトです。

## できること

- IT関連、ドラクエ、関東の夏祭り、横浜イベント、トップニュースのカテゴリ表示
- カテゴリによる絞り込み
- 新着順／おすすめ順の切り替え
- 各カテゴリ最大5件の最新ニュースをRSSから取得

## 起動方法

追加のインストールは不要です。`index.html` をブラウザで開いてください。VS Codeを使う場合は Live Server 拡張機能で開くと確認しやすくなります。

## テスト

Node.js 18以降で以下を実行します。

```bash
npm test
```

## 自動更新

GitHub ActionsがGoogle ニュースのRSS検索から記事を集め、`data/news.json` を更新します。毎日日本時間0時に実行され、IT、ドラクエ、関東の夏祭り、横浜イベント、トップニュースをそれぞれ最大5件表示します。GitHubの **Actions** タブから **Update news** を選び、**Run workflow** を押すとすぐに初回更新できます。

定期実行はGitHub側の都合で数分程度遅れることがあります。RSSの提供状況によっては、一部カテゴリの記事数が5件未満になる場合があります。

## GitHub Pagesへの公開

リポジトリをGitHubへpush後、リポジトリの **Settings → Pages** から、公開元を `main` ブランチの `/ (root)` に設定すると公開URLが作成されます。PrivateリポジトリでPagesが利用できない場合は、GitHubプランまたは公開設定を確認してください。
