# MyNews — 自分専用ニュース

好きなカテゴリのニュースを一画面で見るための、スマホ対応の静的Webサイトです。初期状態では自分だけが閲覧する前提で、GitHub の **Private リポジトリ**として運用します。

## できること

- IT関連、セキュリティ、通信技術、おでかけ、日本のトップ、世界のトップのカテゴリ表示
- カテゴリによる絞り込み
- 新着順／おすすめ順の切り替え
- 各カテゴリ最大5件の最新ニュースをRSSから取得（取得日時・元記事リンク付き）

## 起動方法

追加のインストールは不要です。`index.html` をブラウザで開いてください。VS Codeを使う場合は Live Server 拡張機能で開くと確認しやすくなります。

## テスト

Node.js 18以降で以下を実行します。

```bash
npm test
```

## 自動更新

GitHub ActionsがGoogle ニュースのRSS検索から記事を集め、`data/news.json` を更新します。毎日日本時間0時に実行され、各カテゴリの候補記事を10〜12件ずつ集めます。実際に何件掲載するかは、カテゴリごとのルールに従って日次の更新タスクが選別します。GitHubの **Actions** タブから **Update news** を選び、**Run workflow** を押すとすぐに初回更新できます。

定期実行はGitHub側の都合で数分程度遅れることがあります。RSSの提供状況によっては、一部カテゴリの記事数が5件未満になる場合があります。

## GitHub Pagesへの公開

リポジトリをGitHubへpushする際は、GitHub のリポジトリ作成画面で **Private** を選びます。閲覧者を追加するまで、リポジトリの内容は自分だけが閲覧できます。GitHub Pages は公開URLを発行するため、個人限定のまま運用したい場合は Pages を有効化せず、ローカルで開くかアクセス制限を設定できるホスティングを利用してください。
